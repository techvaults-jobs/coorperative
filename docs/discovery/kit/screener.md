# Society Screener (10 minutes, by phone)

Use this to place each society in the sample (D-003) and to pre-score it as a pilot candidate ([10 §10.2](../10-pilot-selection.md#102-selection-scorecard-score-15-weighted)).

| # | Question | Record |
|---|---|---|
| 1 | What type of institution is the society attached to, if any? | Segment A–H |
| 2 | In which state is it registered? Is it registered with the State or the Federal Director? | State / registrar |
| 3 | Roughly how many active members? | <100 · 100–299 · 300–2,000 · >2,000 |
| 4 | How do members mainly pay: payroll deduction, transfer, cash, or a mix? If payroll, which system (IPPIS, state, company HR)? | Channel / payroll system |
| 5 | How many employers or payroll sources? | Number |
| 6 | Which services: savings, shares, loans (how many products), welfare, trading, investments? | List |
| 7 | How are records kept today: paper, Excel, accounting package, cooperative software (which)? | Tools |
| 8 | Were the last accounts audited? Which year? | Year / auditor type |
| 9 | Have you started NCSR revalidation? Do you have a CVN? | Status |
| 10 | Who could speak with us: treasurer, loan officer, secretary, payroll contact, an auditor, a retired member? | Roles available |
| 11 | Would you be open, in principle, to piloting new software alongside your current system later? | Yes / Maybe / No |

**Include** if segment quotas are not yet full and at least 2 officer roles are available.
**Flag as pilot candidate** if: payroll channel, one payroll source, 300–2,000 members, audited within 2 years, answer to Q11 is Yes or Maybe, and segment A or D.
